# AI-Based Heart Attack Prediction System

A Web application built with **Flask** and **Machine Learning** to predict the risk of a heart attack based on user-provided clinical metrics.

---

## 🛠️ Tech Stack
* **Language:** Python
* **Web Framework:** Flask
* **Machine Learning:** Scikit-learn, Pandas, NumPy
* **Frontend:** HTML, CSS
